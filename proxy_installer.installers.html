build_install_plan() → List[Tuple[str, str]][исходный код]

Формирует полный план установки для режима dry-run.

План включает все реальные команды, которые будут выполнены на сервере, а также техническую паузу перед проверкой статуса сервиса.

Результат:

Список шагов в формате (описание, команда).

Тип результата:

List[Tuple[str, str]]

config

Генерируем случайный секрет (16 байт -> 32 hex-символа), если не передали свой. Для MTProto обычно хватает 16 байт.

Команда journalctl, которую установщик выполняет при падении is-active (для вывода в dry-run).

proxy_installer.installers.factory module

Фабрика установщиков по типу прокси.

Чтобы добавить новый тип: нужно расширить create_installer() (и сам класс установщика). Интерфейс (cli) трогать не нужно - он уже берёт установщик отсюда.
