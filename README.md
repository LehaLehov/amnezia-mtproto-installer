# Автоустановщик Proxy/VPN на VDS (MTProto & Amnezia WG)

## Идея проекта
Сделать удобный консольный скрипт, который берет на себя всю рутину по настройке прокси на "голом" Linux-сервере. Пользователю нужно только указать IP-адрес VDS и пароль (или SSH-ключ). Скрипт сам подключается к серверу, проверяет систему, устанавливает нужные пакеты (MTProto или Amnezia WG), настраивает их и выдает готовые ссылки для подключения. Это решает проблему долгой ручной настройки и копипасты команд из туториалов.

## План разработки (Фичи)

### К Итерации 1:
1. **Модуль SSH-подключения:** надежное подключение к серверу по паролю или RSA-ключу, обработка ошибок (неверный пароль, таймаут, сервер недоступен).
2. **Установка MTProto:** логика установки MTProto прокси (отправка bash-команд, проверка успешности запуска сервиса в systemd).
3. **Базовый CLI-интерфейс:** консольное меню для сбора данных от пользователя (IP сервера, креды, выбор что ставить).

### К Итерации 2:
1. **Поддержка Amnezia WG:** добавление второго протокола (установка через Docker или bash-скрипты, генерация клиентских конфигов).
2. **Генерация ссылок:** парсинг результатов с сервера и вывод красивых кликабельных ссылок (например, `tg://proxy?...`) или генерация QR-кодов в консоли.
3. **Локальный менеджер серверов:** сохранение добавленных серверов в локальный конфиг (JSON/YAML), чтобы при следующем запуске можно было просто выбрать сервер из списка, а не вводить IP и пароль заново.

## Используемая библиотека (не из курса)
**`paramiko`**
Библиотека будет использоваться для реализации всей логики общения с удаленным сервером по протоколу SSH. Это не просто вызов одной функции, а основа всего проекта: открытие сессий, выполнение команд установки в неинтерактивном режиме, чтение потоков вывода (stdout/stderr) для отлова ошибок во время работы, и, возможно, передача конфигурационных файлов через SFTP.
