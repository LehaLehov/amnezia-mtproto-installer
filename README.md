# Автоустановщик Proxy/VPN на VDS (MTProto & Amnezia WG)

## Идея проекта
Скрипт для автоматической установки популярных Proxy и VPN решений (MTProto и Amnezia WG) на чистый VDS сервер. Утилита подключается к серверу по SSH, устанавливает Docker, разворачивает нужный контейнер и выдает готовые ссылки для подключения.

**Участники:** Делаю один.

## Что реализовано (К Итерации 1 и 2)

**Итерация 1 (Завершено):**
- SSH-клиент для подключения по паролю или ключу.
- Базовый интерактивный CLI-интерфейс.
- Установка MTProto Proxy через Docker (с генерацией `tg://proxy...` ссылок).

**Итерация 2:**
- Поддержка Amnezia WG (развертывание контейнера и генерация клиентского конфига).
- Локальный менеджер серверов: сохранение кредов в локальный конфиг.
- Режим `dry-run`: предпросмотр выполняемых команд без реального подключения к VDS (фича от ассистента).

## Используемая библиотека (не из курса)
**`paramiko`**
Используется для реализации логики общения с удаленным сервером по протоколу SSH (открытие сессий, выполнение команд установки в неинтерактивном режиме, чтение потоков вывода для отлова ошибок).
Также используется модуль **`dataclasses`** для удобной типизации конфигураций.

## Важные предупреждения ⚠️

- **Выполнение на сервере:** Скрипт реально выполняет команды (включая установку пакетов, изменение systemd-сервисов) на вашем VDS. Рекомендуется запускать его на тестовом сервере или пустом VDS, чтобы ничего не сломать. Вы можете использовать флаг `--dry-run` для безопасного просмотра команд.
- **Установка Docker:** Установщик Docker использует подход `curl -fsSL https://get.docker.com | bash`. Убедитесь, что вы доверяете официальному скрипту установки Docker, так как он выполняется на сервере от имени root.
- **SSH AutoAddPolicy:** В целях упрощения (так как это учебный проект) в SSH-клиенте используется `paramiko.AutoAddPolicy()`, что означает автоматическое добавление ключа хоста в known_hosts без подтверждения. На реальных продакшн-серверах это может быть небезопасно (риск MITM-атак).
